# 灵数运营管理平台（Token 项目）

> 需求来源：`src/docs/灵数运营管理平台（token-项目）.md`

## 📋 业务与功能

### 1.1 核心目标

在已有运营管理平台框架下，新增 **token 项目管理模块** 的可交互原型，实现接口项目与 token 项目的统一导航结构。本阶段聚焦 token 项目下 6 个子模块，支持多页面路由切换，尽量还原需求文档中的后台管理界面风格。

### 1.2 功能清单

- **数据看板（P0）**：
  - **Tab 切换**：「渠道侧成本情况」与「项目消费情况」两个 Tab，互不堆叠
  - **渠道侧成本**：筛选所属渠道（默认全部）+ 时间段；指标含总 Token 数、总 Token 消费成本（渠道单价×Token，含渠道测试）、总利润、总模型调用次数；趋势图含 Token/消费/渠道成本/利润
  - **项目消费**：仅统计项目管理内项目（排除「灵数运营平台」渠道测试）；默认全部项目总和，可按项目 + 时间段筛选；指标卡片含总 Token、客户侧消费、利润、调用次数（不含总充值费用）
  - **模型调用次数趋势**（两侧 Tab 均有）：图表右上角模型筛选；选单一模型展示该模型柱状图，选「全部模型」按模型分序列对比展示
  - **看板金额保留 2 位小数**（四舍五入）；图表悬停详情中 CNY 类指标同样展示 2 位小数；数据来自 `mockUsageLogs` 聚合
- **使用日志（P0）**：
  - 查询：时间段、**渠道名称**、模型名称、分组、日志类型、项目名称（模糊）
  - 「充值」「扣款」筛选均仅含**项目余额变动**（运营管理）；密钥充值、调用失败扣款等不计入
  - 日志类型：**消耗 / 扣款 / 充值**；项目余额扣款与充值展示规则一致（费用 ±、当前余额）
  - 列表：项目名称（渠道测试为「灵数运营平台」）、类型、时间、渠道、令牌、模型、耗时、Tokens、费用（**2 位小数** 展示）、**当前余额**（仅项目余额充值/扣款有值）、备注
- **项目管理（P0）**：
  - 列表：序号/编号/名称/类型/**状态**/密钥数量、额度限制、项目额度/消费总额、备注、更新时间；操作：**启用/禁用**、**编辑**、密钥配置、**更多**（充值/扣款、使用日志、删除）
  - 查询：项目名称/编号、项目类型、**状态（已启用/已禁用）**
  - 新增/编辑：含**状态（默认开启）**、额度限制；**编辑且原有限额度时项目充值金额禁用**（走充值/扣款）；SaaS 展示账号信息（套餐/用户名/密码）
  - 密钥配置：状态筛选；操作 **禁用/启用 → 编辑 → 更多**（复制链接、复制密钥、充值、删除）；编辑同新增，**原有限额度时额度字段禁用**；密钥充值/扣款与**项目充值/扣款**分弹窗
  - 项目/密钥使用日志 Drawer：含渠道名称筛选
- **渠道管理（P0）**：
  - 列表：**已使用金额 / 已使用 Token 总数**（消耗合计，**含渠道测试**；金额 **2 位小数** 展示）
  - 操作：**编辑 / 禁用·启用 / 测试连接 / 充值/扣款 / 更多**（更多含**查询用量**、**删除**）
  - **充值/扣款** Modal：**仅记账**，不入使用日志；无扣款余额校验；参考余额可为负、不拦调用（上游「余额不足」才影响）；统计区 + 历史记录表
  - **查询用量**：更多菜单进入；Drawer + 筛选；列表同使用日志
  - 创建/编辑：基本信息含**充值金额 (CNY) 只读禁用**（余额走「充值/扣款」记账）；启用禁用；API 访问、模型与分组、模型映射
- **模型定价管理（P0）**
  - **双 Tab**：「模型官方价格管理」+「渠道价格管理」
  - 计费模式：**按 Token** / **按次数**
  - **单价统一 9 位小数**（官方价/渠道价）；**折扣系数 3 位小数**
  - **官方价格 Tab**：查询区含【查询】/【重置】；模型列表分页展示，可新增/编辑/删除；**渠道商数量**（仅统计生效中）、**渠道商摘要**（已生效渠道名称，超 2 个省略）
  - **渠道价格状态**：待生效 / 生效中 / 已失效（仅按生效日期与当前时间；无失效日期字段）
  - **渠道价格列表排序**：渠道价格管理 Tab 按更新时间倒序；其余渠道价格列表按生效日期倒序（晚生效在前）
  - **新增模型**：官方价格下方可配置渠道价格（渠道来源下拉取自渠道管理；价格配置为折扣/自定义；生效日期精确到秒，默认立即生效）
    - 按 Token + 折扣：填折扣系数（3 位小数），10 项渠道价只读预览，保存时 = 官方价 × 系数（9 位小数）
    - 按 Token + 自定义：10 项渠道价可编辑（与官方价字段一致）
    - 按次 + 折扣：每次价格只读预览，保存时 = 官方每次价格 × 系数
    - 按次 + 自定义：每次价格可编辑
  - **渠道价格 Tab**：查询区含【查询】/【重置】；状态筛选（默认全部）；列表分页展示；价格摘要（输入/输出或每次价）；**更新时间**（操作栏前）；列表按更新时间倒序；操作栏详情（生效中/已失效）/ 编辑+删除（待生效）；同模型同渠道仅一条待生效
  - **渠道价格更新**：同模型同渠道仅一条「待生效」；已有生效中价格时须未来生效日排期；到达生效日后切换最新价，用量按当前生效价统计
  - **编辑官方价格**：仅维护官方价格；下方只读展示生效中渠道价格列表（不含待生效/已失效）
  - **渠道价格维护**：独立抽屉；上方只读基本信息+官方价；下方渠道价格配置；选渠道后展示该渠道价格状态
- **分组管理（P0）**：倍率两位小数；「密钥创建可见」控制密钥创建时分组可选

### 1.3 交互要点

- 左侧深色侧边栏 → token 子菜单 → 右侧懒加载页面
- 额度有限：Progress 条展示剩余占比，Tooltip 展示已用/未用/总额
- 额度无限：展示消费总额（原型为 mock 数值）
- 渠道管理「测试连接」→ Message 模拟；「充值/扣款」→ Modal（操作 + 统计 + 历史记录）；「更多 → 查询用量」→ 渠道用量 Drawer
